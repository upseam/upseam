# Upseam

Upseam is Dependabot for APIs. When Stripe, OpenAI, Shopify or your own
backend changes an API you call, Upseam opens a pull request that fixes
mechanical changes and flags the rest. You review it.

- Website: https://upseam.dev
- Docs: https://upseam.dev/docs/
- CLI, locally, with no account and no server:

  ```sh
  npx @upseam/cli inspect stripe .
  ```

## Feedback

Bugs, feedback and requests for a new API provider go to
[GitHub Issues](https://github.com/upseam/upseam/issues/new/choose). Pick a
template; it adds the label.

Private matters (your code, your company) go to
[contact@upseam.dev](mailto:contact@upseam.dev).

## Security

Report vulnerabilities privately to
[contact@upseam.dev](mailto:contact@upseam.dev), not in a public issue. See
[SECURITY.md](SECURITY.md).
